# Getting Started with React Hooks

### 1. `npm install`

Install all dependencies from the package

### 2. `Setup .env file in root directory`

**Inside .env**

```
PORT=3100
```

### 3. `npm dev`

Runs the app in the development mode.<br />
Open [http://localhost:3100](http://localhost:3100) to view it in the browser.

## Other Documentation

### `npm test`

Launches the test runner in the interactive watch mode.<br />
See the section about [running tests](https://facebook.github.io/create-react-app/docs/running-tests) for more information.

### `npm run start:pm2-production`

Run the application with pm2 which using in the server
