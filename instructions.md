**Question**

Appxplore team is having a very big problem deciding where to have lunch every day, a restaurant random picker website is required to aid them to solve this big problem! 

Below are the criteria of the website:
- Restaurant Section
    - Able to Add restaurant with details minimum as below and feel free to add-on:
        - Name
        - Business
        - Address
        - And more...
    * Able to remove the restaurant from List
    * Able to show all/certain restaurants based on criteria(filter).
- Random Picker Section
    * Able to Random Pick a restaurant based on criteria.
    * Able to show previously selected restaurants(history).
- Feel free to be creative and imaginative in the real situation!
- The sections above are just a guide, you can have a more creative way if you think it is suitable for the situation.

**Development Tools**
- Front End - HTML, JavaScript, JQuery, Bootstrap
- Backend - ExpressJS
- Storage - MongoDB (You may use MongoDB Atlas and create a very simple and Free MongoDB to start the test)
